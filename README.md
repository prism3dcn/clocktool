# ClockTool - 极简悬浮时钟

![ClockTool Logo](XTClock.png)  
一款专为「精准读秒」设计的 Android 悬浮时钟应用，启动后以顶层悬浮窗形式显示，黑底黄字高对比度设计，助你在抢购、倒计时等场景中精准把控时间，不遮挡操作界面，轻量无广告。


## 🎯 核心功能

| 功能 | 描述 |
|------|------|
| **顶层悬浮显示** | 启动后时钟悬浮于所有应用之上，不影响其他操作，随时可见 |
| **高对比度UI** | 黑底黄字配色（#000000 背景 + #FFFF00 文字），强光下也清晰可见 |
| **秒级精准更新** | 每秒自动刷新时间，显示格式为 `HH:mm:ss`，无延迟无卡顿 |
| **自由拖动调位** | 长按时钟可拖动至任意位置，避免遮挡关键操作区域（如抢购按钮） |
| **极致轻量** | 安装包体积＜500KB，启动后内存占用＜10MB，不耗电不卡顿 |
| **隐私保护** | 零权限要求（仅需悬浮窗基础权限），不收集任何用户信息，无联网行为 |


## 📱 安装方式

### 1. 直接安装（推荐）
1. 从本仓库下载安装包：[app-release.apk](app-release.apk)（点击链接即可下载）
2. 打开下载的 `app-release.apk`，按照系统提示完成安装（需开启「未知来源应用安装」权限）
3. 首次启动时，系统会提示「请求悬浮窗权限」，点击「前往设置」开启即可


### 2. 手动拷贝安装
1. 将仓库中的 `app-release.apk` 文件拷贝到 Android 设备的存储空间（如 Downloads 文件夹）
2. 在设备上打开「文件管理」，找到 `app-release.apk` 并点击
3. 完成安装并开启悬浮窗权限后，即可使用


## 🚀 使用指南

### 基础操作
1. **启动时钟**：安装并开启悬浮窗权限后，点击应用图标即可启动悬浮时钟
2. **调整位置**：长按悬浮时钟，拖动至屏幕任意位置后松开，位置会自动保存
3. **关闭时钟**：
   - 方法1：下拉手机通知栏，找到「ClockTool 悬浮时钟」通知，点击「关闭时钟」
   - 方法2：打开应用主界面，点击「停止悬浮时钟」按钮


### 适用场景
- **电商抢购**：精准显示秒数，助你在「0点抢购」「限时秒杀」中卡准提交时机
- **考试倒计时**：备考时实时查看时间，避免超时（如行测、申论等时间紧张的考试）
- **直播/活动倒计时**：等待直播开始、活动启动时，无需频繁切换应用看时间
- **日常计时**：做饭、运动等场景中，无需解锁手机即可查看时间

## ❗ 常见问题

### Q1：启动后看不到悬浮时钟？
A：请检查以下两点：
1. 确认已开启「悬浮窗权限」：进入手机「设置 → 应用 → ClockTool → 悬浮窗」，开启权限
2. 检查是否有后台清理工具禁止了应用后台运行：将 ClockTool 加入「后台保护名单」

### Q2：时钟会遮挡其他应用的关键按钮？
A：长按时钟可自由拖动，将其移至屏幕边缘（如顶部状态栏下方、底部导航栏上方），避免遮挡操作区域。

### Q3：应用耗电吗？
A：不会。ClockTool 采用轻量级定时任务，每秒仅更新一次文字显示，无唤醒屏幕、后台联网等耗电行为，连续使用一天耗电＜1%。

### Q4：支持 Android 14 吗？
A：支持。应用最低兼容 Android 5.0（API 21），最高适配 Android 14（API 34），主流机型均可正常使用。
